# Evidence and UX

The showcase combines chat, an evidence inspector, and a source viewer. Each material answer claim has a claim-level `EvidenceRef` containing the claim ID, calculation/query, epistemic status, and references to the next lower layer. Drill-down proceeds answer → calculation → operational state → reconciliation → canonical entity → ER decision → source assertion → mapped field → structured location → original artifact.

The UI displays observed, inferred, reconciled, predicted, proposed, and human-confirmed status distinctly. Users can flag a source, correct a mapping, review a resolution, and see which downstream claims become stale. Chat is an interface to evidence-backed tools, not an authority that bypasses them.
